Hébergement des vidéos

OpenRouter ne lit que des vidéos accessibles par une adresse web. FSM SI EDIT met votre vidéo en ligne juste avant chaque retouche.

Recommandé. Gratuit, fiable, et convertit automatiquement les vidéos iPhone en MP4.

Configurer en 2 minutes
  1. Créez un compte gratuit sur cloudinary.com.
  2. Copiez le Cloud name affiché sur le tableau de bord.
  3. Settings → Upload → Add upload preset → Signing mode : Unsigned → Save.
  4. Copiez le nom du preset ici, puis touchez « Tester ».

La vidéo est déposée sur un hébergeur public gratuit (Litterbox, Uguu ou tmpfiles) et supprimée automatiquement après quelques heures. Pendant ce délai, toute personne qui possède le lien peut la voir.

J’accepte cet envoi public temporaire

Seules les vidéos déjà en ligne (adresse https) pourront être retouchées.
